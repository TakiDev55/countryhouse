# Country House Kit — مود القصر الريفي (Fabric 26.3)

## التركيب
JDK 25 + Fabric Loader 0.20.1+ + Fabric API لـ 26.3.  ثم: `./gradlew build` والجار في `build/libs/`.
(أو ارفعه على GitHub وخذ الجار من Actions → Artifacts)

## الاستخدام
- الوصفة: خشب ×3 / صندوق + بلوك حديد + سرير / كوبلستون ×3  (data/countryhouse/recipe/house_kit.json)
- كليك يمين على أرض مستوية. القصر يبدأ من البلوك اللي ضغطت عليه ويمتد قدامك ولليمين
  (حوالي 43 × 20 بلوك + حديقة 11 بلوك على اليمين)، ويحفر تحته 28 بلوك.

## وش فيه
- قصر دورين: إطار دارك أوك، جدران بلانكس، شرفات، قاعة أمامية عالية بنافذة بنفسجية، سقف موس كوبلستون متقاطع.
- القاعة اليسرى: شيست الإدخال (INPUT) + براميل. تحته أنابيب هوبر تنزل للقبو.
- القبو (درج من القاعة اليسرى): فلتر ريدستون - 12 فلتر، كل واحد له شيست بلون يميزه + شيست أخير لكل شي ما له فلتر.
  الفلاتر بالترتيب من اليسار: حديد، ذهب، نحاس، فحم، دايموند، زمرد، ريدستون، لازورد، حديد خام، كوبلستون، قمح، جزر
- مزارع تحت الأرض (سلم ladder في ركن القبو، عمق ~26 بلوك):
  ايرون جولم (محكم) | إكس بي (قاعة مظلمة + نافذة، الـ XP يظهر على البلوك الذهبي في الممر) | مزرعة محاصيل | حظيرة حيوانات
  كل المنتجات تنتقل تلقائي لشيست INPUT فيفرزها الفلتر.
- حديقة سطحية: محاصيل، حظيرة، Fast Forest (3 شتلات + ديسبنسر عظم + زر).

## ملاحظات
- المود يساعد الفارمات بالكود (يقتل الجولمات والمخلوقات ويجمع الدروبات ويحصد المحاصيل) عشان تشتغل بدون تجربة تصميم ريدستون.
- لو الفلتر الريدستون ما اشتغل: ملف config/countryhouse.properties → javaSorter=true يفرز الـ INPUT بالكود.
- القرويين لازم ينامون أول ليلة قبل ما ينتج الجولم.
