# Country House Kit — مود البيت الريفي (Fabric 26.3)

## التركيب
1. JDK 25 + ماينكرافت Fabric 26.3 (Loader 0.20.1+) + Fabric API.
2. من مجلد المشروع:  `./gradlew build`  (ويندوز: `gradlew.bat build`)
3. الجار يطلع في `build/libs/countryhouse-1.0.0.jar` → حطه في مجلد `mods`.

## الاستخدام
- الوصفة (سرفايفل): خشب ×3 فوق / صندوق + بلوك حديد + سرير بالنص / كوبلستون ×3 تحت.
  (عدّلها من data/countryhouse/recipe/house_kit.json)
- خذ الأيتم بيدك واضغط كليك يمين على الأرض. البيت يبدأ من البلوك اللي ضغطت عليه
  ويمتد قدامك ولليمين (حوالي 26 × 15 بلوك). خله أرض مستوية وفاضية.

## وش يبني
- بيت ريفي: أساس كوبلستون، إطار دارك أوك، جدران بيرش، سقف سبروس، سريرين، ورشة (كرافتنق/أفران/ستون كتر...)
- مخزن كبير: 6 شيستات دبل + 24 برميل + شيستات ميسك والحديد.
  شيستات الجدار الخلفي من اليسار لليمين (يحدها صوف ملون فوقها):
  أبيض = INPUT (حط فيه كل شي) | أسود = JUNK/زبالة | أزرق فاتح = خامات | أحمر = أكل | رمادي = أدوات وأسلحة | بني = بلوكات
  أصفر (الجدار الأيمن) = متفرقات | برتقالي = ناتج فارم الحديد
- فلتر التنضيف: كل ثانيتين المود يفرز اللي في INPUT على الشيستات. تعديل قائمة الزبالة: ItemSorter.java → JUNK
- Fast Forest: 3 مواقع شتلات + ديسبنسر عظم لكل وحدة. اضغط الزر فوق الديسبنسر وتنمو الشجرة.
- مزرعة: قمح/جزر/بطاط مع ماء + حظيرة (بقرتين، خروفين، دجاجتين).
- Iron Golem Farm صغير: مخبأ مقفل تحت البيت (3 قرويين + أسرّة + زومبي محبوس).
  المود يقتل الجولمات ويجمع الحديد تلقائي للشيست البرتقالي.
  لازم القرويين ينامون أول ليلة قبل ما يبدأ ينتج.
